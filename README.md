生物統計学・生物情報処理演習のための「t検定（対応のあるt検定 / 対応無しのt検定）」教材、スライド、および演習課題リポジトリです。

---

## 🌾 【第7回】検定①：1標本t検定 & 対応のあるt検定（スライド教材・演習）

イネの出穂後茎葉重データ（Genotype A vs B の枯れ上がり / Stay-green性）を題材に、母集団と標本、実験誤差、背理法による検定の論理、および対応のあるt検定を学ぶための完全版スライド教材です。

  - ダブルクリックまたはブラウザで直接閲覧できるモダンHTMLスライド（キーボード `←`/`→`/`Space` 操作、`F`キー全画面、コードコピー、目次機能付き）
- **PowerPoint スライド**: [`生物情報処理演習_検定1_改善版スライド.pptx`](./生物情報処理演習_検定1_改善版スライド.pptx)

- **スライドMarkdown原稿**: [`生物情報処理演習_検定1_改善版スライド.md`](./生物情報処理演習_検定1_改善版スライド.md)

## 🧪 【第8回】検定②：対応無しのt検定（独立2標本t検定）インタラクティブWeb教材

独立した2群の平均値の比較、等分散性の仮定、Studentのt検定 vs Welchのt検定を直感的に学べるWeb教材です。

### 🌟 主な教材コンテンツ
- **インタラクティブWeb教材 (`index.html`)**:
  - **対応ありと対応なしの違い**: 生物実験シチュエーションによるインタラクティブ診断
  - **直感シミュレータ**: スライダーで平均値・ばらつき・サンプル数をリアルタイム操作し、t値やp値、棄却域の変化を可視化
  - **理論解説 (Student vs Welch)**: なぜ生物統計学では最初からWelchのt検定が推奨されるのか（二段階検定問題）の解説
  - **生物データ解析ラボ**: イネ系統の茎葉重データや植物ホルモン実験データを即座に解析し、グラフ描画＆レポート用文章を自動生成
  - **RStudio Console完全解読マップ**: 出力テキストをハイライト解説
  - **理解度確認クイズ**: 全5問の即時採点＆解説
- **演習課題ファイル**: `対応無しのt検定_演習ひな型.Rmd`
- **データセット**: `rice_genotypes_unpaired_data.csv`

## 🚀 使い方

### スライド教材の閲覧
```bash
open 生物情報処理演習_検定1_改善版スライド.html
```

### Web教材の閲覧
```bash
open index.html
```
（GitHub Pagesを有効化すると、Web上でそのままアクセス・学習が可能です）

### RStudioでの演習
`ひな型.Rmd` または `対応無しのt検定_演習ひな型.Rmd` をRStudioで開き、「Knit」を実行してください。
事前準備として、以下のパッケージが必要です：
```r
install.packages("readxl")
install.packages("rmarkdown")
```
