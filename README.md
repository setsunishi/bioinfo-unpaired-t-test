# 対応無しのt検定（独立2標本t検定）インタラクティブ教材 & 演習ラボ

生物統計学・生物情報処理演習のための「対応無しのt検定（独立2標本t検定 / Two-sample t-test）」インタラクティブWeb教材および演習課題リポジトリです。

---

## 🌟 主な教材コンテンツ

### 1. インタラクティブWeb教材 (`index.html`)
ブラウザで直接開いて学べるシングルページアプリケーション（SPA）です。
- **対応ありと対応なしの違い**: 生物実験シチュエーションによるインタラクティブ診断
- **直感シミュレータ**: スライダーで平均値・ばらつき・サンプル数をリアルタイム操作し、t値やp値、棄却域の変化を可視化
- **理論解説 (Student vs Welch)**: なぜ生物統計学では最初からWelchのt検定が推奨されるのか（二段階検定問題）の解説
- **生物データ解析ラボ**: イネ系統の茎葉重データや植物ホルモン実験データを即座に解析し、グラフ描画＆レポート用文章を自動生成（Excelからの自由入力も対応）
- **RStudio Console完全解読マップ**: 出力テキストをハイライト解説
- **理解度確認クイズ**: 全5問の即時採点＆解説

### 2. 演習課題ファイル (`対応無しのt検定_演習ひな型.Rmd`)
RStudio上で実際に手を動かして演習課題に取り組むためのR Markdownテンプレートです。
- **課題1**: 出穂後35日茎葉重（SW35）における Genotype A (24系統) と Genotype B (52系統) の比較（両側検定）
- **課題2**: 茎葉重減少量（Decrease = SW5 - SW35, 枯れ上がり度合い）の比較（両側検定）
- **課題3**: 茎葉重減少量の片側検定
- **全体の考察**: 遺伝子型（ジャポニカ型アレル vs インディカ型アレル）とステイグリーン特性の生物学的意義

### 3. データセット (`rice_genotypes_unpaired_data.csv`)
イネ遺伝解析分離集団（76系統）の測定データ（Genotype, SW5, SW35, Decrease）

## 🚀 使い方

### Web教材の閲覧
```bash
open index.html
```
（GitHub Pagesを有効化すると、Web上でそのままアクセス・学習が可能です）

### RStudioでの演習
`対応無しのt検定_演習ひな型.Rmd` をRStudioで開き、「Knit」を実行してください。
事前準備として、以下のパッケージが必要です：
```r
install.packages("readxl")
install.packages("rmarkdown")
```
