「対応あり」と「対応なし」を見分ける

前回学んだ内容

🔗 対応のあるt検定 (Paired t-test)

同じ対象・同一固体・ペアを測定した前後比較。

  • ● 典型例：同じイネ個体における出穂5日目（SW5）と35日目（SW35）の茎葉重
  • ● 標本サイズ：必ず $n_1 = n_2$（ペアが崩れると使えない）
  • ● 数理の本質：差 $d_i = X_i - Y_i$ を計算し、「差の平均が0か」という1標本t検定に帰着させる
今回のテーマ！

⚔️ 対応無しのt検定 (Independent 2-sample t-test)

互いに独立した2つの別グループの平均値を比較。

  • ● 典型例：イネのGenotype A群（24系統）vs Genotype B群（52系統）の茎葉重比較
  • ● 標本サイズ：$n_1$ と $n_2$ が異なっていてもOK！
  • ● 数理の本質：2つの独立な正規分布からのサンプルの差のばらつきを評価する

t検定の直感コア：「シグナル ÷ ノイズ」動的シミュレータ

平均の差（シグナル）が大きく、データのばらつき（ノイズ）が小さく、サンプル数が多いほどt値が大きくなり有意になる！

本質公式 t = (2群の平均値の差) ÷ (差の標準誤差) = Signal / Noise

数理理論：Studentのt検定 vs Welchのt検定

なぜ現代の生物統計学では「最初からWelchのt検定」を使うのが国際標準なのか？

Studentのt検定 (等分散を仮定)

R: var.equal = TRUE

2群の母分散が等しい（$\sigma_1^2 = \sigma_2^2$）という前提のもとで、2群のデータを合わせた合同分散（プールされた分散 $s_p^2$）を計算して標準誤差を求めます。

① 合同分散 (Pooled Variance):
$$s_p^2 = \frac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}$$
② 検定統計量 t値 & 自由度:
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{s_p^2 \left( \frac{1}{n_1} + \frac{1}{n_2} \right)}}, \quad df = n_1 + n_2 - 2$$
⚠️ 弱点: 2群の分散が異なり、かつサンプルサイズが不揃い（$n_1 \ne n_2$）の場合、第一種の過誤（有意水準 $\alpha$）が激しく崩れます。

Welchのt検定 (不等分散対応) 現代標準

R: デフォルト

2群の母分散が異なっていても（$\sigma_1^2 \ne \sigma_2^2$ でも）問題なく使えます。それぞれの群の分散を独立に評価し、自由度を実数に補正します。

① 検定統計量 t値:
$$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
② 自由度 (Welch–Satterthwaiteの式):
$$df = \frac{\left( \frac{s_1^2}{n_1} + \frac{s_2^2}{n_2} \right)^2}{\frac{(s_1^2 / n_1)^2}{n_1 - 1} + \frac{(s_2^2 / n_2)^2}{n_2 - 1}}$$
✅ 特長: 実際に等分散であってもStudent検定とほぼ同じ検出力を保ち、不等分散なら安全に誤りを防ぐ万能手法！

生物統計学の重要コラム：「F検定で等分散性を確かめてからStudentかWelchを選ぶ」はなぜ間違いなのか？

古い教科書では「まずF検定（分散の比の検定）を行い、有意でなければStudent検定、有意ならWelch検定を行う」という手順（二段階検定）が書かれていることがあります。しかし、現代の統計学や生物医学論文ではこの二段階検定は推奨されていません（明確に否定されています）。

理由1: 第一種の過誤の確率が狂う
F検定の判定結果に応じて検定を切り替えると、最終的な有意水準が本来の5%から外れてしまい、誤った結論（偽陽性または検出力低下）を招きます。
理由2: Welchの検定が常に頑健
Welchのt検定は、母分散が等しい場合でもStudentのt検定と実質的に同等に機能するため、最初からWelch検定を使うのが最も安全かつ科学的に誠実です。

👉 だからこそ、R言語の t.test() は何もオプションを指定しないデフォルトの状態で Welchのt検定 を実行する設計になっているのです！

レポート・論文での書き方と「5つの落とし穴」

生物学のレポートや卒業論文で減点されないための重要チェックリスト

⚠️ よくある重大な誤解・落とし穴

  • ❌
    「p > 0.05 だから差がないと証明された」と書く
    正しくは「有意な差は検出されなかった（差があるとは言えない）」。帰無仮説は「証明」されるのではなく「棄却されない」だけです。
  • ❌
    サンプルサイズが異なるのにペアを組んでしまう
    系統や個体が別々の場合は必ず「対応なし」です。行の順番が同じだからといって対応をつけてはいけません。
  • ❌
    平均値だけを見て分散（ばらつき）を無視する
    平均値の差が5gあっても、標準偏差が10gあれば統計的には偶然の誤差の範囲内になり得ます。

✍️ 模範記述スタイル (APA / 生物系学会標準)

検定名、自由度、検定統計量 t値、p値、そして両群の平均値とばらつき（SDまたはSE）を明記するのが国際ルールです。

「イネの出穂後の茎葉重減少量について、Genotype A群（平均 2.21 ± 7.62 g, n = 24）とGenotype B群（平均 11.84 ± 8.45 g, n = 52）をWelchのt検定により比較した。その結果、両群間に統計学的に有意な差が認められた（t(49.34) = -4.95, p < 0.001）。したがって、Genotype Bをもつ系統群はGenotype Aに比べて出穂後の茎葉重減少（枯れ上がり）が有意に大きいことが示された。」
