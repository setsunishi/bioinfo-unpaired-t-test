理論 1/13

統計学的推測：母集団と標本

知りたい全体像と、手元にある有限のデータ

母集団（Population）

  • 研究対象となる全体の集合
  • 例：あるイネ品種のすべての個体の茎葉重
  • 母平均 $\mu$ や 母分散 $\sigma^2$ は「神のみぞ知る未知の定数」

標本（Sample）

  • 実験や調査で実際に測定できた一部の個体
  • 例：圃場で栽培して刈り取った24個体（サイズ $n = 24$）
  • 標本平均 $\bar{x}$ や 不偏分散 $s^2$ は手元で計算可能

⚠️ 実験科学の根本的なジレンマ

標本を採り直すたびに、標本平均 $\bar{x}$ は微妙に変動する（サンプリング誤差 / 実験誤差）。
「標本平均が基準値と違った」からといって、直ちに「母集団全体でも違う」と断定してよいのか？

理論 2/13

中心極限定理と標準誤差（SE）

サンプル数 n を増やすと、標本平均のブレは急激に縮まる
標準誤差： $SE = \frac{s}{\sqrt{n}}$
  • $s$: 標本の標準偏差（個体ごとのばらつき）
  • $n$: サンプルサイズ（測定した個体数）
  • 超重要：個体数 $n$ を4倍に増やせば、平均値の推定ブレは $\frac{1}{2}$ に縮小する！

🎲 サイコロ実験の直感（中心極限定理）

  • サイコロ1個の目は $1 \sim 6$ が均等に出る（平らな一様分布）
  • しかし、「サイコロ10個振った平均値」を1万回計算してヒストグラムを描くと…？
  • 中央（3.5）が尖った綺麗な「正規分布」になる！
  • どんな元の分布であっても、標本平均の誤差は正規分布に従う
理論 3/13

仮説検定の思考法：背理法のアプローチ

「差がある」を証明するために「差がない」と仮定してみる
💡 実験データに差があっても、「たまたま偏ったサンプルを引いただけ（偶然）」という反論を直接論破するのは難しい！

検定の4ステップ（背理法の論理展開）

  1. 仮定を置く：あえて「差はない（母平均の差＝0）」と仮定する（帰無仮説 $H_0$）。
  2. 確率を計算する：もし差がない世界だとしたら、今回観測されたデータのように極端な結果が偶然生じる確率はどれくらいか？（$p$値）
  3. ジャッジする：その確率が極めて低い（例：5%未満）なら…？
  4. 結論：「差がないという最初の前提がおかしい！差はある！」と結論づける（帰無仮説の棄却）。
理論 4/13

帰無仮説（H₀）と対立仮説（H₁）

厳密に分布を計算できる土台を作る

帰無仮説 $H_0$（Null Hypothesis）

  • 「差はない」「効果はない」「変化なし」
  • 数式：$\mu = \mu_0$ または $\mu_1 - \mu_2 = 0$
  • なぜ必要か？：「差＝0」と固定して初めて、確率分布を数学的に計算できるから！
  • 覚え方：新薬を試したが効果が無に帰した（差がなかった）

対立仮説 $H_1$（Alternative Hypothesis）

  • 「差がある」「効果がある」「変化した」
  • 数式：$\mu \neq \mu_0$ または $\mu_1 \neq \mu_2$
  • 実験者が本当に主張したい本命の仮説
  • 帰無仮説が「確率的にあり得ない」と退けられたときに採択される
※ 注意：「差がある」という情報だけでは分布の形を1つに決められないため、直接対立仮説の確率を計算することはできません。だから帰無仮説を経由するのです。
理論 5/13

1標本t検定の統計量（t値とは何か？）

データのズレが偶然の誤差の何倍大きいか（S/N比）
$t = \frac{\text{観測された平均} - \text{期待される基準値}}{\text{標準誤差}} = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$

分子（シグナル）

$\bar{x} - \mu_0$

手元の標本平均と、帰無仮説で想定した基準値との間の「実際のズレの大きさ」

分母（ノイズ）

$s / \sqrt{n} = SE$

偶然のばらつきによって通常生じうる「実験誤差のものさし（1目盛り）」

⚖️ $t \approx 0$：ズレは誤差の範囲内（偶然） | $|t| \ge 2.0$ 前後：ズレは誤差の2倍以上（偶然とは考えにくい！）
理論 6/13

p値の正しい定義（最重要！）

学術論文・研究発表で最も厳しく見られるポイント

⭕ 正しい定義

「帰無仮説（差がない）が真であると仮定したときに、今回観測されたデータ（またはそれ以上に極端なデータ）が得られる確率」

$\rightarrow$ 「もし差がない世界だとしたら、こんな極端な結果が偶然起きる確率はたった〇％しかない」

❌ よくある重大な誤解（使ってはいけない表現）

  • ×「帰無仮説が正しい確率」（事後確率ではありません！）
  • ×「対立仮説が間違っている確率」
  • ×「差がない確率」
理論 7/13

有意水準（α）と棄却域

どこからを「珍しい」と判定するかの境界線

有意水準 $\alpha = 0.05$（5%水準）

  • 科学の世界で慣例として使われる判定基準
  • 「20回に1回以下しか起きない珍しい事象」が起きたら、偶然とは見なさず仮説を捨てる
  • より厳格にする場合は $\alpha = 0.01$（1%水準）を用いる

判定ルール

  • $p < 0.05$（有意差あり、Significant）：
    帰無仮説を棄却 $\rightarrow$「統計学的に有意な差が認められた」
  • $p \ge 0.05$（有意差なし、Not Significant）：
    帰無仮説を保留 $\rightarrow$「差があるとは言えない（※差がないことの証明ではない）」
自由度（$df = n - 1$）： サンプルサイズ $n$ が小さいほど、$t$分布の裾野は正規分布よりも広がり、有意と判定するためのハードル（限界値）が高くなります。
理論 8/13

95%信頼区間（CI）と検定の一致

推定と検定はコインの表と裏

95%信頼区間の意味

「同様のサンプリング実験を100回繰り返したとき、約95回の実験で作った区間が真の母平均を含んでいるような区間」

※ 幅が狭いほど、母平均を精度良く絞り込めていることを示す

検定との美しい 1対1 の対応

  • 95% CI に基準値（0など）が含まれない
    $\iff p < 0.05$（有意差あり！）
  • 95% CI に基準値が含まれている
    $\iff p \ge 0.05$（有意差なし）
🔍 Rで t.test() を実行すると、$p$値（検定）と95%信頼区間（推定）が同時に出力されます！両方の整合性を必ず確認しましょう。
理論 9/13

2種類の過誤（早とちりと見逃し）

生物実験におけるサンプルサイズ設計の重要性
検定の判断 真実：差がない（$H_0$が真） 真実：差がある（$H_1$が真）
差がある！と判断
（帰無仮説を棄却）		 第1種の過誤（$\alpha$エラー / 偽陽性）
「早とちり」（確率 $\alpha = 0.05$） 		正しい判定！
検出力（Power: $1 - \beta$）
差がないと判断
（帰無仮説を採択/保留）		 正しい判定！ 第2種の過誤（$\beta$エラー / 偽陰性）
「見逃し」

検出力（Power）を上げるには？

本当は差があるのに、サンプルサイズ $n$ が小さすぎると第2種の過誤（見逃し）が起きます。
サンプルサイズ $n$ を大きくする、または実験精度を上げてばらつき $s$ を小さくすることで、見逃しを防ぐことができます！

理論 10/13

「対応のある2標本」とは何か？

同一個体・同一系統の前と後を比べる

独立な2標本（対応なし）

  • A群（10人）と B群（別の10人）
  • 「もともと血圧が高い人・低い人」の個体差がノイズとして大きく残る

対応のある2標本（Paired）

  • 同一のイネ個体で「出穂後5日」と「出穂後35日」
  • 同一人物で「投薬前」と「投薬後」
  • 個体ごとの元々の大小のばらつきを相殺（キャンセル）できる！
✨ 個体差という大きなノイズを消し去り、純粋な「処理による変化量（差）」だけを高感度に取り出せるのが最大の強みです。
理論 11/13

対応のあるt検定の本質

実は「差に対する1標本t検定」と完全に同じ！
各ペアの差を計算： $d_i = x_{i, 35} - x_{i, 5}$

差のデータ $D = \{d_1, d_2, \dots, d_n\}$ に対する検定

  • 帰無仮説 $H_0$：差の母平均は 0 である（$\mu_d = 0$）
  • 対立仮説 $H_1$：差の母平均は 0 ではない（$\mu_d \neq 0$）
  • 自由度：$df = n - 1$ （ペア数マイナス1）

Rでは差を手計算する必要なし！

Rの t.test() に2つの列を渡し、paired = TRUE を指定するだけで、内部で自動的に差を計算して検定してくれます。

t.test(x, y, paired = TRUE)
理論 12/13

両側検定 vs 片側検定

変化の方向性を事前に限定するかどうか

両側検定（Two-sided）

  • 問い：「差があるか？（増えたか減ったか問わない）」
  • 対立仮説：$\mu_d \neq 0$
  • 棄却域は左右両端に 2.5% ずつ（合計5%）
  • 原則はこちらを使用（科学論文のデファクトスタンダード）
  • Rオプション：alternative = "two.sided"（デフォルト）

片側検定（One-sided）

  • 問い：「枯れ上がって減ったか？」「薬で熱が下がったか？」
  • 対立仮説：$\mu_d < 0$ または $\mu_d > 0$
  • 棄却域は片側だけに 5% を集中配置
  • 理論的・生物学的に逆方向の変化が絶対にあり得ない場合のみ使用
  • Rオプション：alternative = "less" または "greater"
理論 13/13

【超重要】Rでの片側検定の向き判定ルール

greater か less かで二度と迷わないための鉄則
t.test(A, B, alternative = "...", paired = TRUE)
※ R内部の引き算は常に 第1引数 A － 第2引数 B （$A - B$）

「$A > B$」を主張したいとき

引き算 $A - B$ は 正（$> 0$） になるので：

alternative = "greater"

「$A < B$」を主張したいとき

引き算 $A - B$ は 負（$< 0$） になるので：

alternative = "less"
🌾 本日の課題3（SW35がSW5より小さいか？）：
・書き方①：t.test(table2$SW5, table2$SW35, alternative = "greater", paired = TRUE) （$5日 > 35日$）
・書き方②：t.test(table2$SW35, table2$SW5, alternative = "less", paired = TRUE) （$35日 < 5日$）
※ どちらで書いても $p$ 値は完全に一致します！

実践 6/13

課題1の出力結果を徹底解剖する

Genotype A は枯れ上がりにくい（Stay-green）

数値の読み取り

  • 検定統計量：$t = 1.4209$ （誤差の約1.4倍）
  • 自由度：$df = 24 - 1 = 23$
  • $p$値：$p = 0.1688 > 0.05$
  • 95%信頼区間：$[-1.007, 5.426]$ （0を挟む！）
  • 平均の差：$2.21$ g

判定と結論

  • $p > 0.05$ のため、有意水準5%で帰無仮説は棄却されない
  • 95%信頼区間も 0 を含んでいる
  • 統計的結論：出穂後5日と35日の茎葉重に有意な差があるとは言えない
  • 生物学的考察：Genotype A は出穂後35日を経過しても茎葉重が維持されており、「枯れ上がりにくい」特性をもつ

今日の学びを整理しよう

本日の3大テイクアウェイ

  • 1. 検定は「偶然か本物か」を背理法でジャッジする道具
    帰無仮説（差＝0）が偶然起きる確率（$p$値）が 0.05 未満なら「有意差あり」。$p$値の定義の誤用に注意！
  • 2. 対応のあるt検定は「前後の変化」を捉える強力な手法
    個体差を相殺して差の1標本検定に帰着。片側検定の向き（greater/less）は引き算の正負で判定。
  • 3. データ解析のゴールは「生物学的考察」
    単なる $p$ 値の判定にとどまらず、イネの枯れ上がり・Stay-green特性の意味まで考察する。
